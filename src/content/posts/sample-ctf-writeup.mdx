## Overview

In this challenge, we were provided with a 64-bit ELF binary running glibc 2.35.

```c
void *ptr = malloc(0x80);
free(ptr);
```

## Vulnerability

The program contained a use-after-free (UAF) condition allowing arbitrary pointer overwrite on the heap. By forging a forward link in the tcache bucket, we redirected execution flow to obtain an interactive shell.
