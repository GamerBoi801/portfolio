## Problem
Traditional user-space packet inspection engines incur significant CPU overhead due to kernel-to-user buffer copying under multi-gigabit traffic.

## Approach
Implemented an in-kernel XDP filter written in C that parses packet headers at line rate and forwards flagged flows to a Rust user-space analytics daemon via ring buffers.
